# Edit Kit v1 — Spec (2026-11-07)

## Purpose
An editor installs Claude Code, adds one plugin, says "set up my workspace" — and can then drop
raw footage into the chat and get a tight rough cut with b-roll placed on the right words, checked
and ready for AutoReview. The Whop module "Start with AI → Agentic Editing" teaches exactly this flow.

## Flow (what the editor does)
1. `/plugin marketplace add videoaditor/aditor-kit` → `/plugin install edit-kit@aditor` (+ `aditor-kit@aditor` for QC + AutoReview) → restart.
2. "Set up my workspace" → `edit-setup` installs ffmpeg + whisper-cpp + model, creates `~/aditor-edits/` with house rules, checks Gen.
3. Drag the raw talking head in: "cut this" → `rough-cut` (transcribe → Claude marks false starts / null sentences → pause-cut + 1.15× + −14 LUFS → re-transcribe check).
4. Drag a b-roll folder in: "put b-roll on it" → `broll` (contact frames → Claude labels + places on words → full-frame overlay, VO untouched).
5. `reel-qc` → `autoreview` (from aditor-kit).

## Decisions
- **No API keys.** Claude Code itself is the judge (takes, null sentences, b-roll labels + placement). Whisper runs locally (whisper-cpp). The editing-agent repo's Haiku/OpenAI cells are replaced by the session.
- **Ported, not linked:** `tighten_core.py` is a copy of `editing-agent/runner/tighten/core.py` (pure stdlib, proven). Editing-agent stays private; the kit is public like aditor-kit.
- Word-index drop lists, not timestamps: Claude names words `[i..j]`, the script maps them to times.
- Taste lives in the workspace `CLAUDE.md`; aditor-kit's auto-learn appends corrections there.

## v1.1 (Alan 07.11.: layouts, ≥1 s shots, captions, SFX, cutout clear of the focal point)
Layouts full/split/compare/cutout; Apple Vision person mask + attention saliency (Swift helper, no installs); captions via AppKit text → PNG track; SFX from the editor's own `~/aditor-edits/sfx/` (packs are licensed, never in this public repo); minimum shot 1 s with automatic flash-gap closing; script markers are binding.

## Non-goals
Windows, music, Premiere XML, Telegram session (spec gen #465), Gen generation inside the flow (Gen MCP is only connected + checked).
