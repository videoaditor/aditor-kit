# Editing workspace

Raw files go into `inbox/`. Every edit gets its own folder `jobs/<name>/` (rough-cut and broll write there). Never delete raw footage.

## House rules (Aditor direct-response ads)
- Cut like an outsider: every false start and stutter goes ("it's it's", "and and", half-sentence restarts). The later, complete take wins.
- Sentences that say nothing go: "you know", "but yeah", "so here we go", "as I mentioned". Never rephrase, only remove words.
- Keep intent: lists, parallels ("I use Claude every day, I use Codex every day"), punchlines, deliberate repetition.
- Pace: ads 1.15× with ~2-frame gaps; lessons/long-form 1.1×.
- Something changes on screen every ~1.5 s (60–70 % covered), but nothing stays for less than 1 s — shorter shots stutter.
- Layouts: full b-roll, split screen (b-roll top, speaker bottom), before/after compare, speaker cut out over b-roll — placed so they never cover the b-roll's subject. Never a floating picture-in-picture box.
- The script's markers ([SPLIT SCREEN], green screen, sound design) are binding.
- Captions on, look by niche: health/supplements/telehealth = `highlight` (caps, one key word on a colour block), beauty/home/fashion UGC = `native` (TikTok-native sentence case). Never thick blocky outlines. Proofread against the script; never over a face.
- SFX sparse and under the voice: hits on pain points, whooshes on layout changes, pops on reveals.
- Real-filmed b-roll beats 3D renders. No stock person staring at a phone.
- The voice-over is never re-timed or re-encoded under b-roll.
- Before hand-off: run `reel-qc`, then deliver via `autoreview` (aditor-kit).
